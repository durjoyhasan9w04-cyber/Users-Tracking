# User Hub — DP Tracker

This repository is being prepared for a native Android version of the User Management & DP Tracker.

## Current status

The native Android starter project is under development. It is not yet a complete replacement for the existing Flask + SQLite web app, and no installable APK is published yet.

## Planned native features

- Dashboard and user management
- Daily DP entries (up to five fields)
- Separate bonus records
- Contact history and follow-up lists
- Reports and database backup/restore
- Sports preferences, match calendar, and manual contact reminders

The existing Termux + SQLite web app and its database should be kept intact until a tested migration path is available.
